5. ACCEPTANCE REHEARSALS

For each case record: test ID; job reference; starting state; action taken; expected result; observed result; evidence link; PASS / FAIL / NOT CHECKED; owner; next step; retest date. Blank is NOT CHECKED, never a pass.

A. Duplicate notification, including simultaneous attempts.
Expected: one correct project, with both attempts traceable to it.

B. Old notification arrives after cancellation.
Expected: current eligibility checked; cancelled work is not recreated/reopened.

C. Required customer reference missing.
Expected: no guess; hold, assign, correct and deliberately resume.

D. Project created but response interrupted.
Expected: find or safely resolve the result without duplicate creation.

E. Next action fails after project creation.
Expected: preserve the verified project; complete only unfinished work under the replay rules.

F. Dependency remains unavailable beyond the retry limit.
Expected: retries stop as agreed; owner sees the outstanding job; no false completion.

G. Source notification withheld.
Expected: comparison finds the missing job; recovery yields one verified outcome.

Also test an operator completing work while automation is paused: restart must recognize the manual result and avoid duplicate work.

7. WORKED EXAMPLE — FICTIONAL, NOT A BENCHMARK

Assumptions: 12 distinct eligible paid bookings; one deposit and one intended project each; no cancellations or eligibility changes during this numeric scenario. The three repeat deliveries concern bookings among the ten straightforward cases.

Notifications: 12 original + 3 repeats = 15 deliveries.
Initial job ledger: 10 verified + 1 held + 1 unknown = 12 distinct bookings.

B-112: create request timed out. Investigation finds existing project P-812, verifies the customer and records the link. No new project is created.
B-111: required customer reference missing. Operations corrects it; automation rechecks eligibility and existing work, then creates and verifies one project.

Final projects: 10 initially verified + 1 existing confirmed + 1 newly created = 12 verified projects.
Verify each booking-to-project mapping and no extra project for the same booking. Fifteen deliveries are not fifteen business jobs. If the unknown result cannot be established, keep it unknown with an owner and next review time.
