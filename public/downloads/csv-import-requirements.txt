ILLUSTRATIVE RECONCILIATION (NOT A PRODUCT GUARANTEE)
Initially 20 customers. File has 12 data records plus a header.
Preview: 7 creates (C101-C107), 3 updates (C201-C203), 2 rejected rows (C108 missing name; C204 invalid status).
Partial acceptance confirmed: 7 created + 3 updated + 2 rejected = 12 accounted for.
Customer total: 20 + 7 = 27; rejected existing row C204 unchanged in all fields.
Corrected-only new batch: C108 created, C204 updated. Total: 27 + 1 = 28.
Across batches: 8 creations + 4 updates cover the original twelve rows; 20 + 8 = 28 customers.
Assume no deletions, concurrent edits or downstream actions; saves succeed after confirmation. Real saved values and ownership still need checking.
