2. FICTIONAL Q17 REHEARSAL — REJECT AND REVIEW POLICY
Draft quote Q17 has one line. Total = quantity x unit price.
Assume no tax, discounts, shipping, rounding adjustments or currency conversion.
No approval, customer send, payment or stock reservation takes place.
Alex can edit quantity; Sam can edit unit price. For this rehearsal an authorized reviewer may combine these changes; there is no quantity-based pricing rule.
Version labels below are illustrative names, not an API token specification.

Step 1: Both independently open v7: 12 units x USD 50 = USD 600.
Step 2: Alex saves 15 units against v7 -> v8: 15 x USD 50 = USD 750.
Step 3: Sam tries USD 45 using old v7 form -> reject; saved v8 stays USD 750. Keep Sam's USD 45 edit available for review; do not report it saved.
Step 4: Sam reviews original 12 units, current 15 units, proposed USD 45. Sam explicitly retains 15 units and proposes USD 45. No save yet.
Step 5: Sam saves reviewed values against v8, with no intervening change -> v9: 15 x USD 45 = USD 675.

Expected: 3 save attempts = 2 accepted changes + 1 rejected stale attempt.
Unsafe whole-form alternative: 12 x USD 45 = USD 540, losing Alex's change.
USD 675 - USD 540 = USD 135 difference in draft totals; no revenue claim.
